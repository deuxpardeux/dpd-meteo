# dpd-meteo

This repository is the public weather feed for deux par deux emails.
It contains ONE file, `latest.json`, rebuilt hourly by this repository's GitHub Action from feed code kept in a private repository.
Weather data comes from Environment Canada and Open-Meteo.
It contains no customer data, no product data, and nothing else will ever be added here.
Served at https://deuxpardeux.github.io/dpd-meteo/latest.json.
